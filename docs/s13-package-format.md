不同版本（PK 版本号、语言、补丁）都可能不同。

## 呼吸图在包内的形态

bundle 8 的三层呼吸图每层是一张 1024×1024 的块压缩纹理（DXT5/BC3）。
本工具输出的 32 位 BMP 是**导入前的中间格式**：由你的导入工具
（官方头像工具、San13Pictool 等，自行获取）或自写解析器编码成 DXT5 后
写入包内槽位。分层与羽化逻辑在 BMP 阶段完成，与最终压缩格式无关。

## 列表头像定位

某一版本的列表图集使用每格 100×100 像素、每行 20 格、每帧 200 槽的排布。
可将下式当作**待验证的候选映射**：

```text
frame = slot // 200
row   = (slot % 200) // 20
col   = slot % 20
```

先把目标人物的旧列表截图与解码图集格子比对；确认后才可对该格写入。
若使用块压缩纹理，核实目标格覆盖的 4×4 压缩区块边界，只改目标区块，
随后解码回读整张图集并比较所有非目标区块。不同版本的格子尺寸、帧数、
行列和公式都可能变化。
